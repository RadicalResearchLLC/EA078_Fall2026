20  Elevation and Distance

Today will focus on elevation and distance calculations.

20.1 Elevation

We will use the elevatr package to acquire elevation by distance.

Install the package.

install.packages('elevatr')

Next, get all the standard libraries we need loaded up.

library(tidyverse)
library(sf)
library(tigris)
library(elevatr)
Warning: package 'elevatr' was built under R version 4.6.2

20.1.1 Example 1 - USGS elevation of place centroids

The elevatr package pulls elevation for point datasets. This will show two examples for pulling point data elevations.

First, let’s pull the municipalities of interest.

project_places <- places(state = 'CA', cb = T, year = 2024, progress_bar = F) |> 
  filter(NAME %in% c('Los Angeles',  'Long Beach', 'Anaheim', 'San Diego',  
    'Riverside', 'Irvine', 'San Bernardino', 'Fontana', 'Moreno Valley',
    'Glendale', 'Ontario', 'Lancaster', 'Victorville', 'Newport Beach',
    'Buena Park', 'Redlands', 'Palm Springs', 'Claremont', 
    'Bloomington', 'Mead Valley', 'Santa Fe Springs')) |> 
  st_transform(crs = 4326)

Then, we transform the polygon shapes into centroids to take the geographic center of each municipal place.

place_centroid <- st_centroid(project_places)
Warning: st_centroid assumes attributes are constant over geometries
ggplot() +
  geom_sf(data = project_places) +
  geom_sf(data = place_centroid, color = 'red') +
  theme_void()

20.2 Get elevation data

elevatr has multiple methods to get point elevation data.
- get_elev_point() uses USGS elevation data but is slow
- get_aws_points() uses AWS raster data and allows one to specify a zoom level for resolution of elevation. Significantly faster.

place_elev1 <- get_aws_points(place_centroid, 
                              z = 10, ##zoom level
                              units = 'meters',
                              progress_bar = F)[[1]] ##this returns the first item of the list
Mosaicing & Projecting
Note: Elevation units are in meters.

Opening up the place_elev1 table shows a new column named elevation.

20.3 Measure distances

The function st_distance() can calculate distances between two points. These can be Euclidean or Great Circle distances.

Let’s calculate distances from the Port of Los Angeles. First define the port location.

lat1 <- 33.7673 
lng1 <- -118.2077

portLA <- data.frame(lng1, lat1) |> 
  st_as_sf(coords = c('lng1', 'lat1'), crs = 4326)

distances1 <- as.numeric(st_distance(place_elev1, portLA,

place_elev1$distance <- round(distances1,1)

20.3.1 Visualize data

Let’s make a figure showing elevation and distance from the Port of LA by municipality.

place_elev1 |> 
 ggplot(aes(x = distance, y = elevation, label = NAME)) +
  geom_text(size = 3) +
  theme_bw() +
  labs(x = 'Distance from Port of LA (m)',
       y = 'Elevation (m)')
