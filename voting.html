16.2.2 Tidy and Join data for maps

Let’s try a left join of the geospatial data using the county_fips and GEOID columns. We could also try by county name, but that is less good due to duplicates of names.

countyVotes <- inner_join(US_counties, pres2024, by = c('GEOID' = 'county_fips')) |> 
  select(GEOID, NAME, votes_gop, votes_dem, total_votes, diff, per_point_diff, geometry, STUSPS) |> 
  mutate(percent_diff = 100*per_point_diff)

16.2.4 Chloropleth map - binned

countyVotes |> 
  mutate(color = ifelse(diff>0, 'red', 
                       ifelse(diff < 0, 'blue', 'white'))) |> 
  ggplot() +
  geom_sf(aes(fill = color)) +
  scale_fill_manual(values = c('blue', 'red'), ) +
  theme_map() + #from ggthemes
  coord_sf(xlim =c(-124, -65),
           ylim = c(25, 50))+
  theme(legend.position = 'none')

16.3 Gradient chloropleth map

ggplot(data = countyVotes, aes(fill = percent_diff)) +
  geom_sf() +
  scale_fill_gradient2(low = 'blue', mid = 'white', high = 'red', midpoint = 0) + ##Manual gradient for fill to make a traditional map
  theme_map() + #from ggthemes
  coord_sf(xlim =c(-124, -65),
           ylim = c(25, 50)) +
  labs(fill = '% vote difference')

16.3.1 Bubble map

First, we need to make lat and lng columns for the county to center the bubbles on.

tempTbl <- st_coordinates(st_centroid(countyVotes)) ## create an arry of centroid coordinates  
countyVotes$lng <- tempTbl[,1] ## assign longitude coordinate
countyVotes$lat <- tempTbl[,2] ## assign latitude coordinate
ggplot(data = countyVotes) +
  geom_point(aes(x = lng, y = lat, size = total_votes, color = percent_diff)) +
  scale_color_gradient2(low = 'blue', mid = 'grey90', high = 'red', midpoint = 0) + ##Manual gradient for fill to make a traditional map
  theme_map() + #from ggthemes
  coord_sf(xlim =c(-124, -65),
           ylim = c(25, 50)) +
  theme(legend.position = 'none')

16.3.2 Cartogram

Land doesn’t vote - people do. Let’s squeeze the map to show people. Unfortunately, it is slow, so we’ll just do it for California.

First we need to do some cartographic transformations.

# need first to "change" the projection to Mercator (AKA Google Maps): EPSG: 3857
ca_merc <- countyVotes |> 
  filter(STUSPS == 'CA') |> 
  st_transform(3857)

ca_cartogram <- cartogram_cont(ca_merc, "total_votes", itermax = 15)

# And back to the previous projection
ca_cartogram <- st_transform(ca_cartogram, st_crs(countyVotes)) #or use 4269 for crs
ggplot(data = ca_cartogram, aes(fill = percent_diff)) +
  geom_sf() +
  scale_fill_gradient2(low = 'blue', mid = 'white', high = 'red', midpoint = 0) + ##Manual gradient for fill to make a traditional map
  theme_map() + #from ggthemes
  labs(fill = '% difference')
